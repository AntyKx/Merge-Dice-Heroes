# 新森林城堡戰鬥場景量測紀錄

使用者提供的 941×1672 圖已轉為 `forest-citadel-board_4039b3e9.webp`。印刷棋盤的主要水平邊界約為 y=609、713、828、960、1098；逐列邊界已映射為 16 個絕對 cell，避免將帶透視的圖面強制成一個矩形 CSS grid。

`validate_battle_scene.mjs` 在 415×702、423×689、449×937、475×825 等尺寸確認：滿版預覽有 16 個已填格、選取提示存在，且首格英雄矩形與血條矩形均在首格矩形內；敵軍標記於 Combat 期間有位置變化。後續仍需以實際手機截圖核對每列印刷格邊是否完全貼合，尤其是棋盤的第一列與路線欄中心。

以 `?fullBoardPreview` 完成實際戰鬥流程後，16 個 T 標記與英雄都覆蓋於新圖印刷棋盤；第一列到第四列均保持 cell 內裁切。將以不含偵錯標籤的手機截圖進行最後可讀性確認，並只調整必要的英雄比例或格內邊距。

後續可讀性更新將格內英雄影格由 1.01 倍放大至 1.16 倍，仍使用格內裁切；新城堡生命牌顯示「守望堡生命 25/25」與橫向生命條，置於道路與棋盤之間的場景安全區。實機預覽可讀，未覆蓋波次摘要或主要道路。

滿版預覽確認英雄已明顯放大但仍裁切在 16 格內；道路上可見沿啟用路線前進的發光菱形與細光軌，城堡生命牌移至城堡上方並完整可讀。之後保留原棋盤座標與所有操作列位置。
